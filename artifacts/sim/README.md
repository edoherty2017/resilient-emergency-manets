# Simulation artifact contract

The topology, route, and weather files in this directory are compact simulation
inputs required for clean-clone tests and reproduction. Large traces, caches,
viewers, and exploratory outputs remain ignored.

Pre-audit summaries named `kiosk_summary_*.json`, `sweep*`, or `experiments/*`
were generated before the 2026-07 correctness repair. They are retained locally
as historical evidence, but they must not be described as validated or copied
into a release bundle.

Every corrected run must produce a `run_manifest*.json` with
`scripts/sim_run_manifest.py`. Only results generated by the corrected engines,
with passing regression tests and a matching manifest, belong under
`artifacts/sim/validated/`.

Required manifest bindings:

- exact topology, routes, weather, and simulation config SHA-256 hashes;
- engine, mode, duration, seed, resolved experimental parameters, and the
  runner-reported command (which is not an independent attestation);
- Git commit, branch, dirty status, status listing, tracked-diff hash,
  untracked-file hashes, and the combined worktree fingerprint;
- result file size and SHA-256 hash.

Decision-grade bundles must be launched from a clean committed tree and create
their manifests with `--require-clean`. A dirty-tree manifest binds an
exploratory result to a fingerprint, but the hash alone does not carry the
patch needed to reproduce it.

Do not overwrite historical artifacts. Publish a new corrected bundle and state
which earlier claims it supersedes.

The statewide topology also preserves 52 former `short_link_fspl` values under
`superseded_short_link_policy`, but their active losses are set to 300 dB and
`simulation_eligible=false`. The old rule selected FSPL+26 dB only when it was
less lossy than ITM and had no independent calibration. Do not re-enable it
without field evidence; the builder requires an explicit opt-in for exploratory
counterfactuals.
